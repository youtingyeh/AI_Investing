PART 1 // 從零看懂現代 AI 最基礎架構通則 (How Modern LLMs & Reasoning Models Work)

TOKENIZATION → SELF-ATTENTION → SPARSE MOE → RL REASONING → HARDWARE BOTTLENECK
STEP 01 // 語言數值化

Tokenization 分詞與 Embedding 向量空間

電腦無法直接理解文字、圖片或音訊。AI 的第一步是透過 Tokenizer (如 BPE 演算法) 將文字切分成最小語意單元 Token，再將每個 Token 映射為數千維度的高維度浮點數向量 (Embedding Vector)。

💡 關鍵直覺：在 4096 維空間裡，「晶片 - 台積電 ≈ GPU - 輝達」，語意相近的詞在幾何空間距離極近。
STEP 02 // 核心引擎

Transformer 與自注意力機制 (Self-Attention)

2017 年 Google 發表《Attention Is All You Need》奠定現代 AI 基石。每個 Token 會產生三個向量：Query (查詢 $Q$)、Key (鍵值 $K$)、Value (內容 $V$)，透過矩陣內積計算上下文中任意兩個字之間的關聯權重。

⚡ 硬體對應：計算複雜度隨長度呈 $O(N^2)$ 平方暴增！推理時必須把歷史 $K, V$ 存在記憶體 (KV Cache)，這正是 HBM 高頻寬記憶體 供不應求的根源。
STEP 03 // 架構演進

Dense 稠密模型 vs. Sparse MoE 混合專家

傳統 Dense 模型每生成一個字都要喚醒全部數千億參數，成本極高；現代主流 (GPT-4、Gemini、DeepSeek-V3) 改採 Sparse MoE (混合專家架構)，由 Router 路由器每次僅動態挑出 2~8 個最對口的「專家子網路」啟動。

⚡ 硬體對應：總參數可達 671B~1.8T，但單次推理僅啟動 37B 參數！大幅降低算力消耗，但跨晶片專家通訊極度依賴 NVLink 與 800G/1.6T 矽光子光互連。
STEP 04 // 訓練三部曲

Pre-training → SFT → RL 強化學習推理

1️⃣ 預訓練 (Pre-training)：吞噬數十兆 Token 學習世界知識（通識教育）。
2️⃣ 監督微調 (SFT)：學習人類問答格式。
3️⃣ 強化學習 (RLHF / GRPO)：讓模型在數學、程式碼與邏輯題中自我試錯博弈，湧現出「自我反思與長思維鏈 (Chain-of-Thought)」。

💡 典範轉移：OpenAI o1/o3 與 DeepSeek-R1 證明透過大規模強化學習 (RL)，模型能學會「先慢想再回答」。
STEP 05 // 三大擴展定律

三大 Scaling Laws 與算力投資啟示

當人類高品質自然文本快被讀光時，AI 進入三大擴展律並駕齊驅時代：
• Pre-training Scaling (基礎訓練算力)
• Post-training Scaling (合成數據 + RL 後訓練)
• Test-Time Compute Scaling (推理期思考時間擴展)

💰 投資啟示：推理 (Inference) 不再只是一瞬間吐字，而是每次回答要思考數萬個內部 Token，讓推理算力與客製化 ASIC (AVGO/世芯) 需求暴增 10~100 倍！

PART 2 // 全球 6 大主流 AI 模型公司技術架構與護城河深度對比 (OpenAI vs. Google vs. Anthropic vs. Meta vs. xAI vs. DeepSeek)

ARCHITECTURE · ATTENTION & KV CACHE · RL PARADIGM · HARDWARE SILICON BINDING

MODEL CAPABILITY & EFFICIENCY RADAR

六大前沿模型技術維度量化對比 (推理深度 / 長文本 / 程式碼 / 成本效率 / 多模態)

註：評分基於 SWE-bench (軟體工程)、AIME (數學推理)、長文本檢索與每百萬 Token 推理成本綜合正規化。
核心技術分歧 1：注意力機制與 KV Cache 記憶體壓縮
  • • Google (Gemini 2.0)：採用 Ring Attention (環狀跨晶片注意力) 與交錯局部/全局注意力，在 TPU v5p/v6 全光互連網路上原生支援 200 萬 ~ 1,000 萬 Token 超長上下文。
  • • DeepSeek (V3 / R1)：首創 MLA (Multi-Head Latent Attention，多頭潛在注意力)，將 Key-Value 快取透過低秩矩陣聯合壓縮為潛在向量，使推理時的 KV Cache 記憶體佔用暴降 75%~90%，這也是其 API 定價能做到業界 1/10 的核心數學突破。
  • • Meta (Llama 3/4) & OpenAI：廣泛採用 GQA (Grouped-Query Attention，分組查詢注意力)，多個 Query 共享同一組 Key/Value，在品質與 HBM 頻寬之間取得工業界最穩健平衡。
核心技術分歧 2：強化學習 (RL) 與推理模型路線
  • • OpenAI (o1 / o3 系列)：採用封閉式 過程獎勵模型 (PRM, Process Reward Model) + 強化學習搜尋，對每一步推理步驟打分，在極難的奧林匹亞數學、博士級科學與程式競賽達到最高上限。
  • • Anthropic (Claude 3.7 Sonnet)：首創 Hybrid Reasoning (混合推理單一模型)，不再把「快思考模型」與「慢思考模型」拆成兩個產品，而是讓用戶自由滑動設定 Thinking Token 預算，並專精於真實世界 Agentic Coding (代理寫扣與操作電腦 GUI)。
  • • DeepSeek (R1)：採用 GRPO (Group Relative Policy Optimization)，捨棄了原本耗費雙倍記憶體的 Critic 價值網路，改用同一題抽樣多組回答的相對分數作為獎勵基準，實現極低成本的純 RL 推理湧現。
核心技術分歧 3：原生多模態 (Native Multimodal) vs. 後天拼接
  • • 原生多模態派 (Google Gemini 2.0 / OpenAI GPT-4o)：從預訓練第一天起，就把文字、圖片、音訊、影片全部轉成離散 Token 放進同一個 Transformer 訓練。因此能直接聽出語氣情緒、即時語音打斷，並直接生成圖片與音訊。
  • • 語言與程式碼極致專精派 (Anthropic Claude / DeepSeek)：將幾乎所有參數容量集中在高密度文字、邏輯推理與跨檔案大型軟體工程 (SWE-bench 高達 70%+)，視覺主要服務於圖表解析、PDF 財報閱讀與電腦螢幕座標點擊 (Computer Use)。
核心技術分歧 4：底層算力晶片與台美供應鏈綁定關係
  • • Google：100% 採用自研 TPU v5p / v6 Trillium（與博通 AVGO 共同設計、台積電 2330 代工），擺脫對輝達溢價依賴，具備最低的內部推理邊際成本。
  • • Anthropic：深度綁定 Amazon AWS Trainium 2（由台灣 世芯-KY 3661 設計服務、智邦 2345 / 緯穎 6669 供應硬體）與 Google TPU 雙雲架構。
  • • OpenAI / xAI / Meta：主力依賴 NVIDIA H100/H200/Blackwell GB200（受惠 鴻海 2317 / 廣達 2382 / 奇鋐 3017 / 台達電 2308），同時 Meta 大量導入 AMD MI300X/MI325X 負責推理，OpenAI 亦攜手博通開發自研 ASIC。
